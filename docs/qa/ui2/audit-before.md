# UI before audit

Settings and beater selection were embedded in the start poster; credits expanded in the same poster. Every element with auto/scroll overflow or measurable overflowing dimensions is listed below. Raw geometry includes descendants of collapsed details (which can retain bounds without being painted), and font/border rounding; those entries are diagnostics, not assertions of visible clipping. Settings and carousel are not separate screens in the original UI.
