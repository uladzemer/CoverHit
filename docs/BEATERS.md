## Geometry regression references (2026-10-09)

Loop width / total length is checked within ?10% using the visible head bounding
box (including strands), with uniform world scale at idle, wind-up and strike.
Nominal metre dimensions: Soviet 0.18 / 0.65, rattan 0.25 / 0.75, Sonne 0.19 /
0.76. The sources above do not specify head widths for the remaining models;
procedural design references are plastic 0.195 / 0.55, Victorian 0.238 / 0.75,
and bamboo 0.173 / 0.60. These are design dimensions, not historical measurements.
Closed loops omit duplicated end knots and use TubeGeometry's parallel-transport
frames with closed-loop seam correction. Flattened bamboo tube scaling is removed;
the molded plastic ribbon retains its documented 10 ? 4 mm physical section.
