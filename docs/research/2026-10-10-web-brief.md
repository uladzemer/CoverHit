# Веб-бриф для CoverHit (three r186, WebGL2) — 2026-10-10

Проверено живыми запросами 2026-10-10: npm registry (three 0.186.1, three.quarks 0.17.1 MIT, @techstark/opencv-js 5.0.0-release.1 Apache-2.0, sharp 0.35.5 Apache-2.0), Commons API, Blender Extensions, Sketchfab API. Пометка «(по памяти)» = не проверено в этой сессии.

## 1. Бельё/ткань на ветру
**Рекомендация:** не симулировать ткань в рантайме. Один Blender-бейк (или Node/Verlet-бейк) на 2-3 клипа ветра (штиль / бриз / порыв) -> VAT -> инстансинг; вертексный шейдер лишь смешивает клипы по `uGust` (blend двух сэмплов текстуры + фаза на экземпляр).
- **VAT (Blender):** [Vertex Animation Toolkit](https://extensions.blender.org/add-ons/vat/) v1.0.12, Blender 4.2+, GPL-3.0-or-later (лицензия аддона; на экспортируемые данные не распространяется — но проверить). Track A = `positions.exr/png` + `normals.png` + `.glb`, работает в WebGL2. Track B (storage buffer) только WebGPU — не брать. Cloth надо предварительно «Bake All Dynamics»; число вершин константно.
- **three-vat:** [manthrax/three-vat](https://github.com/manthrax/three-vat) — патчит стандартный материал через onBeforeCompile, инстансинг со сдвигом времени/скоростью на экземпляр, экспортёр Blender. Лицензия в репо не указана, версия three не заявлена — только как референс, код лучше написать самому (~60 строк).
- **Процедурный флаг:** vertex shader: смещение по нормали = амплитуда(y от крепления) × (sin(k·x + ω·t + фаза) + FBM-шум), порыв = медленный шум по времени, умножает амплитуду. Нулевой бейк, 1 draw call через `InstancedMesh`. Хуже на складках.
- **three.js example `webgl_animation_cloth`** (по памяти): CPU Verlet, один кусок — как источник Verlet-кода для Node-бейка, не для рантайма.
- **Ветер:** одна модель `wind(x,t) = base + gust`; base 1-3 м/с (Бофорт 2-3: 1.6-5.4 м/с), порыв до 5 м/с = шум 0.1-0.5 Гц. Один uniform `uWind` на ткань, пыль и мотыльков.
- Gotcha: `InstancedMesh` + VAT: текстуру брать `NearestFilter`, `HalfFloatType`; frustum culling считает по базовой геометрии — задать `boundingSphere` вручную.

## 2. Пыль
**Рекомендация:** своя система на `THREE.Points`/инстансированных квадах (1 draw call), не three.quarks: в README у three.quarks нет шума/turbulence, soft particles и освещения (проверено fetch'ем README; перечислены force fields, texture animation, sub-emitters, plugin behaviours). Если всё же брать: [three.quarks](https://github.com/Alchemist0823/three.quarks) 0.17.1, MIT, peer `three>=0.182`.
- **Адвекция:** curl-noise от 3D value-noise в вершинном шейдере (позиция = f(seed, t), без CPU-цикла) + ветер `uWind`; расширение и затухание альфы по времени жизни.
- **Спрайты:** flipbook 4x4/8x8 дыма, альфа-премульт. CC0: [Kenney Smoke Particle Assets](https://opengameart.org/content/smoke-particle-assets) (77 PNG, CC0, [zip 13.2 MB](https://opengameart.org/sites/default/files/smokeParticleAssets.zip)); [Kenney Particle Pack](https://opengameart.org/content/particle-pack-80-sprites) (CC0).
- **Soft particles:** нужна depth-текстура сцены (`DepthTexture` в render target, отдельный pass дорог) — для низкой пыли у земли дёшево заменить на fade по высоте над землёй.
- **Подсветка низким солнцем:** фаза Хеньи-Гринштейна в фрагменте: `hg(cosθ,g=0.6)`, `cosθ = dot(viewDir, -sunDir)`; яркость × тень (CSM/ shadow map не сэмплить на частицах — дорого, достаточно высоты и направления).
- **Осаждение:** в конце жизни — шлейф затухает; декаль на земле не нужна.

## 3. Мотыльки
**Рекомендация:** процедурный мотылёк (2 крыла = 2 треугольных/квад-меша с альфа-текстурой, хлопок в вертексном шейдере), 10-30 штук `InstancedMesh`, траектория — коррелированное случайное блуждание + слабый фототаксис к лампе. Фото-сканы тяжёлые.
- **Модели CC0:** на Sketchfab (ffish.asia / floraZia.com, CC0) всё 270k-1M граней, напр. [Silk Moth](https://sketchfab.com/3d-models/none-83b97ba2b2874f81874fbf15de1a96ba) (474k) — нужна децимация до <1k; для вида 9-16 мм это перебор. Платные RenderHub не брать.
- **Полёт:** скорость: `v = v + (rand·σ − k·(v−v0))dt`, поворот ограничен; Леви — редкие длинные прыжки; ограничить объёмом вокруг лампы/двора; взмахи 25-40 Гц невидимы — рисуем blur/альфа-крыла.
- **Вид (Wikipedia, [платяная моль](https://en.wikipedia.org/wiki/Common_clothes_moth)):** тело 6-7 мм, размах 9-16 мм (обычно 12-14), охристо-жёлтая, задние крылья серо-белёсые, пучок рыжих волос на голове, нити-усики ~4/5 длины крыла. Важно: платяная моль **не** летит на свет, предпочитает бегать и тёмные места — для «летящей на лампу» взять пищевую моль (Plodia) или обобщённую ночную.

## 5. Вырезание ковра
**Рекомендация:** OpenCV.js в Node: сегментация (GrabCut/цвет) -> `findContours` -> `approxPolyDP` в 4 вершины -> `getPerspectiveTransform` -> рект. Ручная правка 4 углов как fallback.
- **@techstark/opencv-js** 5.0.0-release.1 (Apache-2.0, ~14.7 MB unpacked, без нативной сборки — на Windows ставится без компилятора). Node: `await cvReadyPromise`; `Mat.delete()` обязательно. Наличие `grabCut`/`createLineSegmentDetector` в сборке проверить `typeof cv.grabCut` (по памяти).
- **sharp** 0.35.5 (Apache-2.0, Node >=20.9; готовые бинарники) — только ввод-вывод/ресайз/PNG, детекции нет.
- **QA:** подгонка прямой МНК по контуру каждой стороны, RMS отклонения < 0.5 px; утечка фона: доля пикселей маски вне ±2 px от края < 1%; визуально — оверлей на шахматке.
- **Subpixel:** градиент вдоль нормали + параболическая интерполяция; ЗАМЕЧАНИЕ: JPEG-блоки дают ±0.5 px.
