# Generated laundry assets

`positions.bin` and `manifest.json`: original CoverHit procedural data generated
by `node scripts/bake-laundry.mjs`, deterministic damped-Verlet cloth and rope.
No external images, models, executable code or licensed stock were downloaded.
Fabric patterns and weave are generated locally in `src/scene/yard/laundry.js`.
See `docs/research/laundry-wind.md` for the primary documentation references.
