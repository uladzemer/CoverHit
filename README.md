# CoverHit — выбей советский ковёр

Браузерная 3D-аркада во дворе хрущёвки на закате. [Играть](https://uladzemer.github.io/CoverHit/).

## Возможности

- Мягкое тело ковра на Ammo/Bullet: замах, удары, ветер и перекидывание через турник.
- Музейные сканы ковров, очистка двух сторон, ритмические комбо, ловля моли и открываемые выбивалки.
- Двор с фотографическими фасадами, GPU-пылью и процедурным звуком.
- HTML-интерфейс в стиле советского плаката; настройки звука, прицела и графики.
- Desktop-профиль full и облегчённые lite/minimal для телефонов; WebGL2, three r186, Vite 6.

## Управление

На компьютере наведите мышь, зажмите левую кнопку для замаха и отпустите для удара.
`F` перекидывает ковёр; `Esc` открывает меню. Ритм ударов повышает комбо.
На телефоне удерживайте палец на игровой области, перемещайте для прицеливания и отпускайте для удара.
Прицел сдвинут над пальцем. Используйте экранные кнопки перекидывания, меню и звука.
Выход пальца за игровую область или отмена касания отменяет замах.

## Разработка и проверки

Нужен Node.js 22+. Команды из корня проекта:

```sh
npm ci
npm run dev
npm test
npm run build
```

`build` пересобирает ковры из исходных сканов, затем lite-ассеты и приложение.
`npm run build:public` использует готовые ковры из `public/carpets/` и обновляет lite-копии;
этот путь используется в CI и не требует исходных фотографий.
Тесты, которым нужны локальный Chrome или Python/OpenCV, пропускаются при отсутствии этих инструментов.
Тесты комбо используют фиксированные игровые кадры и замороженные часы.

Проверка сборки в условиях GitHub Pages (POSIX shell):

```sh
COVERHIT_BASE=/CoverHit/ npm run build
COVERHIT_BASE=/CoverHit/ npm run preview -- --host 127.0.0.1 --port 5189
RELEASE_URL=http://127.0.0.1:5189/CoverHit/ npm run verify:release
node scripts/smoke-pages.mjs http://127.0.0.1:5189/CoverHit/
```

В PowerShell задайте `$env:COVERHIT_BASE='/CoverHit/'` и `$env:RELEASE_URL` перед соответствующей командой.
`verify:release` требует Playwright Chromium и WebKit (`npx playwright install chromium webkit`);
на Windows может использовать установленный Chrome через `CHROME_PATH`.
Он проверяет desktop, iPhone/WebKit и Pixel, сетевые ошибки, ошибки консоли и предупреждения шейдеров.

## Публикация

GitHub Pages настроен на GitHub Actions. Push в `main` или ручной запуск
`.github/workflows/pages.yml` выполняет `npm ci`, тесты, публичную сборку, загрузку артефакта и deploy.
Отдельная smoke-проверка требует HTTP 200 для страницы и всех JS-файлов из `assets/`, указанных в HTML.
Для project site базовый путь — `/CoverHit/`.

`npm run publish:public -- --dry-run` проверяет snapshot текущего HEAD без отправки.
`npm run publish:public -- owner/repo` публикует snapshot отдельным коммитом в указанном публичном репозитории.
Нужны Bash, Git, Node и авторизованный `gh`. Незакоммиченные изменения в snapshot не входят.
QA-изображения удаляются из snapshot, затем проверка печатает количество файлов, MiB и лицензии.
Любой путь с `envato`, `stock`, `licensed-stock`, ZIP, символическая ссылка или файл больше 8 MiB запрещён.
Правило применяется также к именам исходников: snapshot с `scripts/stock-build.mjs` будет отклонён.
Перед использованием этого строгого экспортёра нужен подготовленный HEAD без запрещённых путей и с рабочими импортами.

## Локальные лицензированные материалы

Envato Elements используется только локально. `assets-src/**/envato/`, `public/carpets/envato-*`,
`public/carpets/manifest.local.json` и `public/yard/stock/` остаются gitignored.
Обычная production-сборка удаляет локальные ковры и весь каталог stock из `dist/` и не запрашивает их манифесты.
Разработка допускает эти запросы; `VITE_STOCK=1` включает их явно.
`COVERHIT_INCLUDE_STOCK=1` сохраняет файлы для личной сборки и устанавливает `VITE_STOCK=1`; такую сборку не публикуют.
QA PNG с локальными лицензированными материалами остаются gitignored.

## Известные ограничения

- Нужен WebGL2. Эмуляция iPhone в Playwright не воспроизводит завершение вкладки операционной системой на реальном телефоне.
- В lite/minimal фиксированный выходной буфер защищает WebKit от потери canvas; поворот экрана может смягчать изображение.
- ANGLE/D3D выдаёт X3595 для N8AO PoissionBlur и X4122 для three.js PMREM. Они записаны в QA и NOTICE; собственный PCSS использует явный LOD 0 и сохраняет штатный возврат shadow.
- Полярная контактная коррекция ковра при бросках пока имеет известные отклонения; измерения и непройденные критерии записаны в `docs/CORE.md` и `docs/qa/flipcontact/`.
- Бюджеты High: не более 150 draw calls и 6 ms CPU/frame; фактическая скорость зависит от устройства. Проверки и ограничения измерений — `docs/qa/perf/`.
