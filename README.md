# CoverHit — выбей советский ковёр

Браузерная 3D-аркада: во дворе хрущёвки на закате ковёр перекинут через турник, его надо выбить выбивалкой.
Зажми кнопку мыши — замах, отпусти — удар. Ритм даёт комбо, `F` — перекинуть ковёр на другую сторону,
в полёте можно поймать моль, а соседка ворчит, если бить слишком часто.

**Играть:** https://uladzemer.github.io/CoverHit/

## Запуск у себя

```
npm install
npm run dev        # разработка, http://localhost:5173
npm test           # тесты чистой логики и физических инвариантов
npm run build      # продакшен-сборка в dist/
```

Нужен Node 22+. Физика ткани — Ammo.js (Bullet), рендер — three.js, всё остальное — ванильный JS.

## Что внутри

- `src/carpet/` — ткань на мягком теле Bullet, перекидывание руками, столкновение слоёв, бахрома, грязь.
- `src/scene/` — двор: фасады по фото, ветер, бельё (запечённая ткань), освещение «золотого часа».
- `src/fx/` — пыль и моль. `src/ui/` — интерфейс в стиле советского плаката.
- `docs/` — архитектура, спеки, исследования и QA-отчёты; `scripts/` — сборка и проверка ассетов.
